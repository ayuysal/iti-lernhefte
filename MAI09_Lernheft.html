Kapitel 1

Reihen und Konvergenzkriterien

Zuletzt gelesen

Eine Reihe ist der Grenzwert ihrer Partialsummen. Die Kriterien sagen, ob sie konvergiert – wogegen, muss man selbst herausfinden.

Definition 1.1

Ist (ai) eine Zahlenfolge, so heißt die Reihe konvergent gegen den Summenwert (Reihenwert) S, wenn die Folge der Partialsummen konvergiert:

∑i=1∞ ai := limp→∞ ∑i=1p ai = S

Existiert dieser Grenzwert nicht, divergiert die Reihe. Die Schreibweise mit ∞ ist nur eine Kurzform für den Grenzwert der Partialsummen.

Die geometrische Reihe – der wichtigste Baustein

∑i=0p qⁱ = (qp+1 − 1)/(q − 1)   (endlich, q ≠ 1)

∑i=0∞ qⁱ = 1/(1 − q)   für |q| < 1

Beispiel: q = ¾ → ∑ = 1/(1 − ¾) = 4.   q = ½ → ∑i=0∞(½)ⁱ = 2, also ∑i=1∞(½)ⁱ = 1 („Schokoladenhalbierung“).

Dagegen divergiert ∑ i, denn die geschlossene Form p(p+1)/2 geht gegen ∞.

1.2 Die vier Kriterien

KriteriumPrüfgrößeAussage
Quotientenq = limi→∞ |ai+1 / ai|q < 1 → konvergent · q > 1 → divergent · q = 1 → keine Aussage
Wurzelq = limi→∞ i√|ai|ebenso: q < 1 konvergent, q > 1 divergent, q = 1 keine Aussage
Leibnizalternierende Reihe ∑(−1)ibikonvergiert, wenn bi monoton fallend ist und gegen 0 geht
notwendiges Kriteriumlimi→∞ ai≠ 0 → Reihe divergiert. = 0 beweist nichts
Die harmonische Reihe ∑ 1/i

Das Standardbeispiel für q = 1: Quotienten- und Wurzelkriterium liefern 1 – keine Aussage. Die Glieder gehen gegen 0, das notwendige Kriterium ist also erfüllt. Trotzdem divergiert sie. Merksatz: ai → 0 ist notwendig, aber nicht hinreichend.

Rechentrick beim Quotientenkriterium: Fakultäten kürzen über (i+1)! = i!·(i+1); danach entscheidet der Grad von Zähler und Nenner. Beispiel ∑ i¹⁷/i! → Quotient = (i+1)¹⁶/i¹⁷ → 0 < 1, also konvergent. Beispiel ∑ 2ⁱ → Quotient = 2 > 1, divergent.

1.3 Absolute Konvergenz, Majorante, Minorante

BegriffInhalt
absolut konvergent∑|ai| konvergiert. Daraus folgt Konvergenz von ∑ai – die Umkehrung gilt nicht
MajorantenkriteriumGilt |ai| ≤ bi und konvergiert ∑bi, so konvergiert ∑ai (absolut)
MinorantenkriteriumGilt ai ≥ ci ≥ 0 und divergiert ∑ci, so divergiert ∑ai

Als Vergleichsreihen dienen fast immer die geometrische Reihe (konvergent für |q| < 1), die harmonische Reihe ∑1/i (divergent) und die Reihen ∑1/iα (konvergent für α > 1).

Kapitel 2

Potenz- und Taylorreihen

Zuletzt gelesen

Reihen, deren Glieder von x abhängen – und die Frage, für welche x sie konvergieren.

Potenzreihe (Def. 2.1) und Konvergenzradius (Def. 2.2)

P(x) = ∑k=0∞ ak·(x − x₀)k

Es gibt ein r ≥ 0 (den Konvergenzradius), sodass die Reihe für |x − x₀| < r absolut konvergiert und für |x − x₀| > r divergiert. Über die Randpunkte |x − x₀| = r sagt der Radius nichts – sie müssen einzeln geprüft werden. Der Konvergenzbereich ist das Intervall inklusive der konvergenten Randpunkte.

Berechnung des Konvergenzradius (Sätze 2.1 / 2.2)

r = limk→∞ | ak / ak+1 |    (aus dem Quotientenkriterium)
r = 1 / limk→∞ k√|ak|      (aus dem Wurzelkriterium)

Für x₀ ≠ 0 verschiebt sich nur der Mittelpunkt: Konvergenz für x ∈ (x₀ − r, x₀ + r).

Operationen (Sätze 2.3/2.4): Innerhalb des Konvergenzbereichs darf man Potenzreihen gliedweise addieren, differenzieren und integrieren; der Konvergenzradius bleibt dabei erhalten.

Taylorreihe und Taylorpolynom (Def. 2.3)

T(x) = ∑k=0∞ f(k)(x₀)/k! · (x − x₀)k

Das Taylorpolynom n-ten Grades ist die endliche Summe bis k = n – die beste polynomiale Näherung von f in der Nähe von x₀. Für x₀ = 0 spricht man von der MacLaurin-Reihe.

Die wichtigsten Reihenentwicklungen (x₀ = 0):

ex = 1 + x + x²/2! + x³/3! + …      (r = ∞)
sin x = x − x³/3! + x⁵/5! − …       (r = ∞)
cos x = 1 − x²/2! + x⁴/4! − …      (r = ∞)
1/(1−x) = 1 + x + x² + x³ + …    (r = 1)
ln(1+x) = x − x²/2 + x³/3 − …    (r = 1)

Die Sätze 2.5 und 2.6 klären, wann die Taylorreihe die Funktion tatsächlich darstellt: genau dann, wenn das Restglied für n → ∞ gegen null geht.

Kapitel 3

Fourierreihen

Zuletzt gelesen

Periodische Funktionen als Summe von Sinus- und Cosinusschwingungen – auch dann, wenn die Funktion Sprünge hat.

Definition 3.2 – Fourierreihe einer 2π-periodischen Funktion

Ff(x) = a₀/2 + ∑n=1∞ ( an·cos(nx) + bn·sin(nx) )

an = (1/π) ∫02π f(x)·cos(nx) dx   (n = 0, 1, 2, …)
bn = (1/π) ∫02π f(x)·sin(nx) dx   (n = 1, 2, …)

Achtung: a₀ wird in der Reihe halbiert – a₀/2 ist der Mittelwert der Funktion über eine Periode.

Symmetrie spart die halbe Arbeit

Ist f gerade (achsensymmetrisch), so sind alle bn = 0 → reine Cosinusreihe.
Ist f ungerade (punktsymmetrisch), so sind alle an = 0 → reine Sinusreihe.
Vor dem Integrieren also immer erst auf Symmetrie prüfen.

Satz 3.1 – wann stellt die Reihe die Funktion dar?

Voraussetzungen: (1) [0, 2π] lässt sich in endlich viele Teilintervalle zerlegen, auf denen f stetig und monoton ist; (2) an jeder Unstetigkeitsstelle existieren links- und rechtsseitiger Grenzwert.

Dann gilt: Überall, wo f stetig ist, ist Ff(x) = f(x). An jeder Sprungstelle liefert die Reihe das arithmetische Mittel der einseitigen Grenzwerte:

Ff(x) = ( f⁻(x) + f⁺(x) ) / 2

Das ist mehr, als Taylorreihen leisten: Die Funktion muss nicht einmal überall stetig sein.

Für Funktionen mit der Periode T statt 2π (Def. 3.3, Satz 3.2) ersetzt man nx durch nωx mit ω = 2π/T und integriert über eine volle Periode, mit dem Vorfaktor 2/T statt 1/π.

Kapitel 4

Fourier- und Laplacetransformation

Zuletzt gelesen

Von der Zeitfunktion zur Bildfunktion – und zurück. Die Laplacetransformation macht aus einer Differenzialgleichung eine algebraische Gleichung.

4.1 Fouriertransformation

Verallgemeinert die Fourierreihe auf nichtperiodische Funktionen: Aus der Summe über diskrete Frequenzen wird ein Integral über ein kontinuierliches Spektrum. Die Rücktransformation ist hier oft schwierig – genau das macht die Laplacetransformation attraktiver.

Definition 4.3 – Laplacetransformation

F(s) = ℒ{f(t)} = ∫0∞ f(t)·e−st dt

f heißt Originalfunktion oder Zeitfunktion, F die Bildfunktion. Formal ist s komplex mit positivem Realteil – in der Praxis und in diesem Heft genügt s > 0 reell. Das uneigentliche Integral muss existieren.

Korrespondenztabelle

f(t)F(s) = ℒ{f(t)}
11/s
t1/s²
tⁿn!/sn+1
eat1/(s − a)
sin(ωt)ω/(s² + ω²)
cos(ωt)s/(s² + ω²)
e−at·sin(ωt)ω/((s+a)² + ω²)
e−at·cos(ωt)(s+a)/((s+a)² + ω²)
Die vier Sätze (4.4–4.7)

Linearität:  ℒ{a₁f₁ + a₂f₂} = a₁·ℒ{f₁} + a₂·ℒ{f₂}

Ähnlichkeitssatz:  ℒ{f(at)} = (1/a)·F(s/a)   (a > 0)

Verschiebungssatz:  ℒ{f(t − a)} = e−as·F(s)   (a > 0, f(t−a) := 0 für t < a)

Dämpfungssatz:  ℒ{e−at·f(t)} = F(s + a)

Merkhilfe: Verschiebung im Zeitbereich → Faktor e−as im Bildbereich. Dämpfung im Zeitbereich → Verschiebung im Bildbereich. Beispiel: ℒ{e−tcos t} = (s+1)/((s+1)²+1) = (s+1)/(s² + 2s + 2).

Satz 4.8 – Ableitungssatz (der Schlüssel zu den DGLen)

ℒ{f′(t)}  = s·F(s) − f(0)
ℒ{f″(t)} = s²·F(s) − s·f(0) − f′(0)

allgemein: ℒ{f(n)} = sⁿF(s) − sn−1f(0) − sn−2f′(0) − … − f(n−1)(0)

Die Anfangswerte stecken direkt in der Formel – deshalb löst die Laplacetransformation Anfangswertprobleme in einem Zug, ohne nachträgliche Konstantenbestimmung.

Lösung eines linearen Anfangswertproblems – drei Schritte

(i) Laplacetransformation auf beide Seiten der DGL anwenden, dabei Satz 4.8 für die Ableitungen benutzen.
(ii) Die entstehende algebraische Gleichung nach der Bildfunktion Y(s) auflösen.
(iii) Y(s) nötigenfalls per Partialbruchzerlegung in einfache rationale Terme zerlegen und mit der Korrespondenztabelle zurücktransformieren.

Beispiel: y″ + 5y′ + 4y = 0 mit y(0) = 2, y′(0) = 1.

(s²Y − 2s − 1) + 5(sY − 2) + 4Y = 0
Y·(s² + 5s + 4) = 2s + 11
Y = (2s + 11)/((s+1)(s+4))
Partialbruch: Y = 3/(s+1) − 1/(s+4)
y(t) = 3e−t − e−4t

Probe: y(0) = 3 − 1 = 2 ✓  ·  y′(t) = −3e−t + 4e−4t, y′(0) = −3 + 4 = 1 ✓

Übungsaufgaben mit Lösungswegen

Zuletzt gelesen

Die Aufgabentypen des Hefts, vollständig durchgerechnet.

Ü.1Teleskopsumme: Konvergenz und ReihenwertKapitel 1

Bekannt ist ∑i=1p 1/(i(i+1)) = p/(p+1). Zeigen Sie, dass ∑i=1∞ 1/(i(i+1)) konvergiert, und bestimmen Sie den Reihenwert.

Lösungsweg

Die geschlossene Form ist gegeben – man muss nur den Grenzwert der Partialsummen bilden:

lim(p→∞) p/(p+1) = lim(p→∞) 1/(1 + 1/p) = 1
Die Reihe konvergiert, der Reihenwert ist S = 1.

Hintergrund: 1/(i(i+1)) = 1/i − 1/(i+1) – in der Summe heben sich alle inneren Terme auf (Teleskopsumme), übrig bleibt 1 − 1/(p+1).

Ü.2Quotienten- und Wurzelkriterium anwendenKapitel 1

Untersuchen Sie: a) ∑ k/5k (Quotientenkriterium) · b) ∑ (5/4)k (Wurzelkriterium) · c) ∑ 2k/k!

Lösungsweg
a) |a(k+1)/a(k)| = [(k+1)/5^(k+1)] · [5^k/k] = (k+1)/(5k) lim = 1/5 < 1 → KONVERGENT b) ᵏ√|a(k)| = ᵏ√((5/4)^k) = 5/4 q = 5/4 > 1 → DIVERGENT (Glieder wachsen sogar) c) |a(k+1)/a(k)| = [2^(k+1)/(k+1)!] · [k!/2^k] = 2/(k+1) lim = 0 < 1 → KONVERGENT
Faustregel: Fakultät im Nenner schlägt jede Potenz – solche Reihen konvergieren immer. Beim Wurzelkriterium lohnt der Blick, ob ak schon die Form (…)k hat; dann kürzt sich die Wurzel sofort weg.
Ü.3LeibnizkriteriumKapitel 1

Untersuchen Sie ∑k=1∞ (−1)k/k sowie ∑k=1∞ (−1)k·k/(k+1).

Lösungsweg
1) b(k) = 1/k • monoton fallend: 1 > 1/2 > 1/3 > … ✓ • Nullfolge: lim 1/k = 0 ✓ → nach Leibniz KONVERGENT (alternierende harmonische Reihe) 2) b(k) = k/(k+1) • lim k/(k+1) = 1 ≠ 0 ✗ → das NOTWENDIGE Kriterium ist verletzt → DIVERGENT
Beide Leibniz-Bedingungen müssen erfüllt sein. Fall 1 zeigt außerdem: Die Reihe konvergiert, aber nicht absolut (∑1/k divergiert) – man nennt das bedingte Konvergenz.
Ü.4Konvergenzradius und -bereichKapitel 2

Bestimmen Sie den Konvergenzradius von a) ∑ k³/2k · xk und b) ∑ (x−2)k/(k·2k), und untersuchen Sie bei b) die Randpunkte.

Lösungsweg
a) a(k) = k³/2^k r = lim |a(k)/a(k+1)| = lim [k³/2^k] · [2^(k+1)/(k+1)³] = lim 2·k³/(k+1)³ = 2 → Konvergenz für |x| < 2 b) a(k) = 1/(k·2^k), Entwicklungspunkt x₀ = 2 r = lim |a(k)/a(k+1)| = lim [(k+1)·2^(k+1)] / [k·2^k] = 2 → Konvergenz für |x − 2| < 2, also 0 < x < 4 Randpunkte: x = 4 → ∑ 2^k/(k·2^k) = ∑ 1/k → divergent (harmonisch) x = 0 → ∑ (−2)^k/(k·2^k) = ∑ (−1)^k/k → konvergent (Leibniz)
a) r = 2  ·  b) r = 2, Konvergenzbereich [0, 4) – der linke Rand gehört dazu, der rechte nicht. Genau deshalb muss man die Randpunkte immer einzeln prüfen.

Ü.6Fourierreihe einer RechteckfunktionKapitel 3

Bestimmen Sie die Fourierreihe der 2π-periodischen Funktion f(x) = −1 für 0 ≤ x < π und f(x) = 1 für π ≤ x < 2π, und geben Sie den Wert der Reihe bei x = 0 an.

Lösungsweg
a₀ = (1/π)[∫₀^π (−1)dx + ∫_π^2π 1 dx] = (1/π)(−π + π) = 0 aₙ = (1/π)[∫₀^π (−1)cos(nx)dx + ∫_π^2π cos(nx)dx] = (1/π)[ −sin(nx)/n |₀^π + sin(nx)/n |_π^2π ] = 0 (sin(nπ)=0) bₙ = (1/π)[∫₀^π (−1)sin(nx)dx + ∫_π^2π sin(nx)dx] = (1/π)[ cos(nx)/n |₀^π − cos(nx)/n |_π^2π ] = (2/(nπ))·(cos(nπ) − 1) → n gerade: bₙ = 0 ; n ungerade: bₙ = −4/(nπ)

Damit ergibt sich die reine Sinusreihe

F(x) = −(4/π)·[ sin x + sin(3x)/3 + sin(5x)/5 + … ]
Bei x = 0 ist eine Sprungstelle: f⁻(0) = 1 (Wert von links, also aus dem Intervall davor) und f⁺(0) = −1. Nach Satz 3.1 liefert die Reihe das arithmetische Mittel (1 + (−1))/2 = 0 – und tatsächlich sind alle Sinusterme bei x = 0 gleich null ✓
Ü.7Laplacetransformierte mit den Sätzen bestimmenKapitel 4

Berechnen Sie a) ℒ{3 + t} · b) ℒ{e−2t·t} · c) ℒ{e−at·cos(ωt)}.

Lösungsweg
a) Linearität (Satz 4.4): ℒ{3 + t} = 3·ℒ{1} + ℒ{t} = 3/s + 1/s² b) Dämpfungssatz (Satz 4.7) mit f(t) = t, F(s) = 1/s²: ℒ{e^(−2t)·t} = F(s + 2) = 1/(s + 2)² c) Dämpfungssatz mit f(t) = cos(ωt), F(s) = s/(s² + ω²): ℒ{e^(−at)·cos(ωt)} = F(s + a) = (s + a) / ((s + a)² + ω²)
Merksatz für c): Im Bildbereich überall s durch (s + a) ersetzen – auch im Zähler. Ein häufiger Fehler ist, nur den Nenner anzupassen.
Ü.8Rücktransformation mit PartialbruchzerlegungKapitel 4

Bestimmen Sie die Zeitfunktion zu F(s) = (s − 2)/(s·(s − 8)).

Lösungsweg
Ansatz: (s − 2)/(s(s − 8)) = A/s + B/(s − 8) s − 2 = A(s − 8) + B·s s = 0: −2 = −8A → A = 1/4 s = 8: 6 = 8B → B = 3/4 F(s) = (1/4)·(1/s) + (3/4)·(1/(s − 8))

Rücktransformation mit der Tabelle: 1/s → 1 und 1/(s − a) → eat.

f(t) = ¼ + ¾·e8t. Probe für t = 0: ¼ + ¾ = 1, und der Grenzwertsatz liefert lims→∞ s·F(s) = 1 ✓
Ü.9Anfangswertproblem über Laplace lösenKapitel 4

Lösen Sie y″ + 3y′ + 2y = 0 mit y(0) = 1 und y′(0) = 0.

Lösungsweg
(i) transformieren – Anfangswerte stecken im Ableitungssatz: [s²Y − s·1 − 0] + 3[sY − 1] + 2Y = 0 (ii) nach Y auflösen: Y(s² + 3s + 2) = s + 3 Y = (s + 3)/((s + 1)(s + 2)) (iii) Partialbruchzerlegung: (s+3)/((s+1)(s+2)) = A/(s+1) + B/(s+2) s = −1: 2 = A → A = 2 s = −2: 1 = −B → B = −1 Y = 2/(s+1) − 1/(s+2)
y(t) = 2e−t − e−2t
Probe: y(0) = 2 − 1 = 1 ✓ · y′(t) = −2e−t + 2e−2t → y′(0) = 0 ✓ · Einsetzen in die DGL ergibt 0 ✓

Der Vorteil gegenüber dem klassischen Weg: keine nachträgliche Bestimmung von Integrationskonstanten – die Anfangswerte sind von Anfang an eingebaut.

A.3Fourierreihe einer abschnittsweise definierten FunktionKapitel 3

Bestimmen Sie die Fourierreihe zu f auf dem Grundintervall 0 ≤ x < 2π (abschnittsweise definiert, mit einem Sprung bei π) und geben Sie den Wert der Reihe an den Stellen x₁ = 0 und x₂ = π an.

Lösungsweg
1. a₀ = (1/π)∫₀^2π f(x) dx (Integral abschnittsweise aufteilen!) 2. aₙ = (1/π)∫₀^2π f(x)cos(nx) dx 3. bₙ = (1/π)∫₀^2π f(x)sin(nx) dx 4. Reihe aufschreiben – a₀ dabei HALBIEREN 5. Werte an x₁ und x₂ über Satz 3.1

Ist der Integrand abschnittsweise definiert, zerfällt jedes Integral in zwei Teile (0…π und π…2π). Für den Teil mit f(x) = x braucht man die partielle Integration:

∫ x·cos(nx) dx = x·sin(nx)/n + cos(nx)/n² ∫ x·sin(nx) dx = −x·cos(nx)/n + sin(nx)/n²
Der eigentliche Prüfpunkt sind die Werte an x₁ und x₂: Beide sind Stellen, an denen die Funktion springt. Nach Satz 3.1 liefert die Reihe dort nicht den Funktionswert, sondern das arithmetische Mittel (f⁻ + f⁺)/2 der einseitigen Grenzwerte. Bei x = 0 sind das die Werte am linken Rand des Grundintervalls und am rechten Rand (Periodizität!).
A.4Laplacetransformation hin und zurückKapitel 4

a) Laplacetransformierte von f(t) = e−at·cos(ωt) · b) mit Partialbruchzerlegung die Zeitfunktion zu einer gebrochen rationalen Bildfunktion.

Lösungsweg

a) Dämpfungssatz auf die Tabellenkorrespondenz anwenden:

ℒ{cos(ωt)} = s/(s² + ω²) ℒ{e^(−at)·cos(ωt)} = F(s + a) = (s + a) / ((s + a)² + ω²)

b) Vorgehen bei einer Bildfunktion der Form F(s) = Z(s)/N(s):

1. Nenner faktorisieren, z. B. s² − 8s = s(s − 8) 2. Ansatz A/s + B/(s−8) aufstellen 3. mit dem Nenner durchmultiplizieren 4. GESCHICKTE Werte einsetzen (die Nullstellen des Nenners!) 5. jeden Summanden einzeln mit der Tabelle zurücktransformieren

Durchgerechnet für F(s) = (s − 2)/(s(s − 8)):

s − 2 = A(s − 8) + Bs s = 0: −2 = −8A → A = 1/4 s = 8: 6 = 8B → B = 3/4 f(t) = 1/4 + (3/4)·e^(8t)
Die nützlichen Korrespondenzen für Teil b): 1/s → 1 · 1/(s−a) → eat · 1/(s−a)² → t·eat · ω/(s²+ω²) → sin(ωt). Bei doppelten Nullstellen im Nenner muss der Ansatz zusätzlich einen Term mit dem Quadrat enthalten.
