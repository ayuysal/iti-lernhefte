Kapitel 1

Zweidimensionale Zufallsgrößen

Zuletzt gelesen

Zwei Zufallsgrößen gleichzeitig betrachten: gemeinsame Verteilung, Randverteilungen – und die Frage, ob sie zusammenhängen.

Gemeinsame Verteilung und Randverteilungen

Eine zweidimensionale Zufallsgröße (X, Y) wird im diskreten Fall durch die Verteilungstabelle P(X = xi, Y = yj) beschrieben. Die Randverteilungen entstehen durch Aufsummieren:

P(X = xi) = ∑j P(X = xi, Y = yj)   (Zeilensumme)
P(Y = yj) = ∑i P(X = xi, Y = yj)   (Spaltensumme)

Unabhängigkeit: X und Y sind unabhängig, wenn für alle Paare gilt
P(X = xi, Y = yj) = P(X = xi) · P(Y = yj). Ein einziges Gegenbeispiel genügt zur Widerlegung.

Aus dem Vektor (X, Y) macht man mit einer Funktion g(x, y) wieder eine Zahl – erst dann sind Erwartungswert und Varianz sinnvoll (Def. 1.6, Satz 1.4):

E(g(X,Y)) = ∑i,j g(xi, yj) · P(X = xi, Y = yj)

Rechenregeln für Erwartungswert und Varianz

E(X + Y) = E(X) + E(Y)        immer (Satz 1.5)
V(X) = E(X²) − (E(X))²        Verschiebungssatz
V(aX) = a²·V(X)
V(X + Y) = V(X) + V(Y) + 2·cov(X,Y)
V(X₁ + … + Xₙ) = V(X₁) + … + V(Xₙ)  nur bei Unabhängigkeit (Satz 1.11)

Merksatz: Erwartungswerte darf man immer addieren, Varianzen nur bei Unabhängigkeit (genauer: bei Unkorreliertheit).

1.2 Kovarianz und Korrelationskoeffizient

Definitionen

cov(X, Y) = E[(X − E(X))·(Y − E(Y))] = E(X·Y) − E(X)·E(Y)

ρ(X, Y) = cov(X, Y) / ( √V(X) · √V(Y) )

Der Korrelationskoeffizient ρ liegt immer zwischen −1 und +1. |ρ| = 1 bedeutet exakten linearen Zusammenhang, ρ = 0 heißt unkorreliert.

Die zentrale Asymmetrie

Unabhängig ⟹ unkorreliert. Die Umkehrung gilt nicht: Unkorreliertheit misst nur den linearen Zusammenhang. Zwei Größen können unkorreliert und trotzdem stark (nichtlinear) voneinander abhängig sein.

1.3 Der Zentrale Grenzwertsatz

Satz 1.12

Sind X₁, X₂, … unabhängig und identisch verteilt mit Erwartungswert μ und Varianz σ², so gilt für die Summe

P( (∑i=1n Xi − n·μ) / (σ·√n) ≤ x ) → Φ(x)   für n → ∞

Die Summe verhält sich also näherungsweise normalverteilt – ganz gleich, wie die einzelnen Xi verteilt sind. Sie müssen nur denselben Erwartungswert und dieselbe Varianz haben.

Dabei ist E(∑Xi) = n·μ und V(∑Xi) = n·σ², die Standardabweichung der Summe also σ·√n.

Kochrezept: Ereignis „∑Xi ≤ a“ standardisieren, indem man auf beiden Seiten n·μ abzieht und durch σ·√n teilt; dann Φ-Tabelle ablesen.

Beispiel (100 Würfelwürfe): μ = 3,5 · E(X²) = 91/6 = 15,167 · σ² = 15,167 − 12,25 = 2,917 · σ = 1,708.

P(∑Xi ≤ 400) = P( (∑Xi − 350)/(10·1,708) ≤ 2,927 ) ≈ Φ(2,927) = 0,9985

Nützlich: Φ(−x) = 1 − Φ(x), und P(a ≤ Z ≤ b) = Φ(b) − Φ(a).

Kapitel 2

Deskriptive Statistik

Zuletzt gelesen

Daten beschreiben statt Wahrscheinlichkeiten berechnen: Häufigkeiten, Lage- und Streumaße, Zusammenhänge.

Grundbegriffe

Grundgesamtheit = alle Objekte, über die eine Aussage getroffen werden soll. Stichprobe = die tatsächlich untersuchte Teilmenge, n = Stichprobenumfang. Merkmal = die erhobene Eigenschaft, Merkmalsausprägung = ihr konkreter Wert.

Skalenniveaus: nominal (nur unterscheidbar, z. B. Farbe) · ordinal (zusätzlich Rangfolge, z. B. Schulnote) · metrisch/kardinal (Abstände sinnvoll, z. B. Körpergröße). Mittelwerte setzen metrische Daten voraus.

Darstellungsmethoden (2.2): absolute Häufigkeit hi, relative Häufigkeit fi = hi/n (Summe = 1), kumulierte Häufigkeiten, Klassenbildung sowie Säulen-, Balken-, Kreis- und Histogramm-Darstellungen.

2.3 Lage- und Streumaße

arithmetisches Mittel:  x̄ = (1/n)·∑ xi
Median:  mittlerer Wert der geordneten Liste (bei geradem n: Mittel der beiden mittleren)
Modus:  häufigste Ausprägung

empirische Varianz:  s² = (1/(n−1))·∑ (xi − x̄)²
empirische Standardabweichung:  s = √s²
Spannweite:  R = xmax − xmin

Wichtig: Bei der empirischen Varianz steht n − 1 im Nenner, nicht n – nur so ist die Schätzung erwartungstreu (siehe Kapitel 3). Der Median ist robust gegen Ausreißer, das arithmetische Mittel nicht.

2.4 Korrelation und Regression

Empirische Kennzahlen einer zweidimensionalen Stichprobe

sxy = (1/(n−1))·∑ (xi − x̄)(yi − ȳ)   (empirische Kovarianz)

r = sxy / (sx·sy)   (empirischer Korrelationskoeffizient, −1 ≤ r ≤ 1)

Praktische Rechenform: ∑(xi − x̄)(yi − ȳ) = ∑xiyi − n·x̄·ȳ – man braucht also nur ∑x, ∑y, ∑x², ∑y², ∑xy.

Regressionsgerade (Methode der kleinsten Quadrate)

y auf x:  ŷ = a + b·x  mit  b = sxy/sx²  und  a = ȳ − b·x̄

x auf y:  x̂ = c + d·y  mit  d = sxy/sy²  und  c = x̄ − d·ȳ

Es gibt zwei verschiedene Regressionsgeraden – welche gefragt ist, steht in der Aufgabe („X in Abhängigkeit von Y“ heißt: x auf y, also durch sy² teilen). Beide gehen durch den Schwerpunkt (x̄, ȳ). Es gilt b·d = r².

Korrelation ist keine Kausalität

Ein hoher Betrag von r belegt einen linearen Zusammenhang in den Daten – keine Ursache-Wirkung-Beziehung. Und r misst nur Linearität: Ein perfekter parabolischer Zusammenhang kann r ≈ 0 liefern.

Kapitel 3

Schätzen und Testen

Zuletzt gelesen

Von der Stichprobe zurück auf die Grundgesamtheit – mit ehrlicher Angabe der Unsicherheit.

3.1 Schätzfunktionen und ihre Güte

erwartungstreu (unverzerrt): E(Θ̂) = Θ – im Mittel trifft die Schätzung den wahren Wert.
konsistent: Die Schätzung wird mit wachsendem n immer genauer (V(Θ̂) → 0).
effizient: unter allen erwartungstreuen Schätzern die kleinste Varianz.

Die Standardschätzer: x̄ für μ und s² (mit n−1!) für σ². Genau der Nenner n−1 macht s² erwartungstreu.

Satz 3.4/3.5: Die Summe normalverteilter Größen ist wieder normalverteilt; für X̄ gilt E(X̄) = μ und V(X̄) = σ²/n, die Standardabweichung des Mittelwerts ist also σ/√n. Standardisiert ergibt das U = (X̄ − μ)/(σ/√n), standardnormalverteilt.

3.2 Vertrauensintervalle (Konfidenzintervalle)

SituationIntervallVerteilung
μ, σ bekanntx̄ ± c · σ/√nStandardnormal­verteilung, c aus 2Φ(c) − 1 = γ
μ, σ unbekanntx̄ ± t · s/√nt-Verteilung mit n−1 Freiheitsgraden
σ² (μ unbekannt)[ (n−1)s² / χ²o , (n−1)s² / χ²u ]χ²-Verteilung mit n−1 Freiheitsgraden

Gängige Quantile der Standardnormalverteilung: γ = 0,90 → 1,645 · γ = 0,95 → 1,96 · γ = 0,99 → 2,576.

Zwei Fallen

1. Beim Varianzintervall stehen die Quantile über Kreuz: Das obere χ²-Quantil steht im Nenner der unteren Grenze. Das Intervall ist deshalb nicht symmetrisch.
2. Interpretation: Ein 95-%-Intervall bedeutet, dass bei unendlich vielen Stichproben etwa 95 % der so berechneten Intervalle den wahren Wert enthalten. Für das eine konkrete Intervall gilt: Der wahre Wert liegt darin oder nicht – es ist ein Maß der Unsicherheit, keine Wahrscheinlichkeitsaussage über μ.

3.3 Hypothesentests

Regel 3.1 – zweiseitiger Test des Erwartungswerts

H₀: μ = μ₀ gegen H₁: μ ≠ μ₀. Irrtumswahrscheinlichkeit α wählen, γ = 1 − α, Quantil c bestimmen. Annahmebereich:

μ₀ − c·σ/√n  ≤  x̄  ≤  μ₀ + c·σ/√n

Liegt x̄ darin, wird H₀ beibehalten (nicht: bewiesen!) – man hat keinen Grund zur Ablehnung. Liegt x̄ außerhalb, wird H₀ zugunsten von H₁ abgelehnt.

Gleichwertig: Prüfen, ob μ₀ im Vertrauensintervall [x̄ ± c·σ/√n] liegt. Beide Wege führen zur selben Entscheidung.

Warum „Irrtumswahrscheinlichkeit“? Bei α = 0,05 landet der Stichprobenmittelwert in 5 % der Fälle selbst bei korrekter H₀ außerhalb des Annahmebereichs – man lehnt eine richtige Hypothese ab. Das ist der Fehler 1. Art; der Fehler 2. Art ist umgekehrt das Beibehalten einer falschen H₀.

Ein- oder zweiseitig?

Zweiseitig (H₁: μ ≠ μ₀), wenn Abweichungen in beide Richtungen kritisch sind – der Ablehnungsbereich liegt dann je zur Hälfte an beiden Rändern (Quantil zu 1 − α/2). Einseitig (H₁: μ > μ₀ oder μ < μ₀), wenn nur eine Richtung interessiert – dann liegt das gesamte α an einem Rand (Quantil zu 1 − α).

Ist σ unbekannt, tritt an die Stelle von σ die empirische Standardabweichung s und an die Stelle der Normalverteilung die t-Verteilung mit n−1 Freiheitsgraden – genau wie beim Vertrauensintervall.

A.1Randverteilungen, Erwartungswerte, Varianzen6 Pkt.

Zweidimensionale Zufallsgröße (X, Y) mit der Verteilungstabelle

Y = 1Y = 2Y = 3
X = 21/81/41/8
X = 41/81/81/4

Bestimmen Sie die Randverteilungen von X und Y sowie E(X), E(Y), V(X), V(Y).

Lösungsweg

Zuerst die Probe: Alle acht… hier sechs Wahrscheinlichkeiten müssen sich zu 1 addieren: 1/8+1/4+1/8+1/8+1/8+1/4 = 8/8 ✓

Randverteilung X (Zeilensummen): P(X=2) = 1/8 + 1/4 + 1/8 = 1/2 P(X=4) = 1/8 + 1/8 + 1/4 = 1/2 Randverteilung Y (Spaltensummen): P(Y=1) = 1/8 + 1/8 = 1/4 P(Y=2) = 1/4 + 1/8 = 3/8 P(Y=3) = 1/8 + 1/4 = 3/8 Probe: 1/4+3/8+3/8 = 1 ✓
E(X) = 2·(1/2) + 4·(1/2) = 3 E(X²) = 4·(1/2) + 16·(1/2) = 10 V(X) = 10 − 3² = 1 E(Y) = 1·(1/4) + 2·(3/8) + 3·(3/8) = 0,25 + 0,75 + 1,125 = 2,125 = 17/8 E(Y²) = 1·(1/4) + 4·(3/8) + 9·(3/8) = 0,25 + 1,5 + 3,375 = 5,125 = 41/8 V(Y) = 41/8 − (17/8)² = 5,125 − 4,515625 = 0,609375 = 39/64
E(X) = 3 · V(X) = 1 · E(Y) = 17/8 = 2,125 · V(Y) = 39/64 ≈ 0,609

Nebenbei: X und Y sind nicht unabhängig – P(X=2, Y=2) = 1/4, aber P(X=2)·P(Y=2) = 1/2 · 3/8 = 3/16.

A.2Verteilungsfunktion von Z = max(X, Y)6 Pkt.

X und Y seien unabhängig mit den Verteilungsfunktionen FX(x) und FY(y). Bestimmen Sie die Verteilungsfunktion von Z = max(X, Y).

Lösungsweg

Der entscheidende Gedanke: Das Maximum ist genau dann höchstens z, wenn beide Größen höchstens z sind.

F_Z(z) = P(Z ≤ z) = P( max(X,Y) ≤ z ) = P( X ≤ z UND Y ≤ z ) ← Kern der Aufgabe = P(X ≤ z) · P(Y ≤ z) ← hier geht die Unabhängigkeit ein = F_X(z) · F_Y(z)
FZ(z) = FX(z) · FY(z)

Zur Kontrolle das Gegenstück: Für W = min(X, Y) gilt das Argument über das Komplement – W > w heißt, dass beide größer als w sind:

F_W(w) = 1 − P(X > w)·P(Y > w) = 1 − (1 − F_X(w))·(1 − F_Y(w))
A.325 Messwertpaare: Kennzahlen und Regressionsgerade6 Pkt.

Zur Abhängigkeit der Bruchdehnung X vom Kohlenstoffgehalt Y wurden 25 Messwertpaare ermittelt. a) Mittelwerte, empirische Standardabweichungen und Korrelationskoeffizient. b) Regressionsgerade für X in Abhängigkeit von Y.

Lösungsweg

Bei 25 Wertepaaren lohnt eine Arbeitstabelle mit fünf Spalten – daraus folgt alles:

Spalten: x_i | y_i | x_i² | y_i² | x_i·y_i Summen: ∑x | ∑y | ∑x² | ∑y² | ∑xy x̄ = ∑x/n ȳ = ∑y/n s_x² = (∑x² − n·x̄²)/(n−1) s_y² = (∑y² − n·ȳ²)/(n−1) s_xy = (∑xy − n·x̄·ȳ)/(n−1) r = s_xy / (s_x · s_y)

b) „X in Abhängigkeit von Y“ heißt: X ist die abhängige Größe, also die Regression x auf y:

x̂ = c + d·y mit d = s_xy / s_y² und c = x̄ − d·ȳ
Die häufigste Fehlerquelle dieser Aufgabe: durch sy² teilen, nicht durch sx². Kontrolle: Setzt man y = ȳ ein, muss x̂ = x̄ herauskommen. Erwartung hier: Ein höherer Kohlenstoffgehalt macht Stahl spröder, also negatives r und negative Steigung.
